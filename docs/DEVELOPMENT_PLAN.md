# dayribbon 개발 계획 — 전체 20단계

작성일: 2026-11-25
근거 문서: `docs/PRODUCTION_TRANSITION_PLAN.md` (데모→정식 전환 분석)

## 개발 원칙

1. 기존 완료 기능을 임의로 변경·삭제하지 않는다.
2. 각 단계 완료 후 테스트 실행 + `DEVELOPMENT_PROGRESS.md` 갱신.
3. 데모 데이터와 실제 데이터를 명확히 구분한다.
4. LLM 미연결 상태에서는 "규칙 기반 분석"임을 명시한다.
5. 최종 의사결정은 항상 사람이 수행한다.

## 향후 상위 계획 (20단계 이후, 별도 문서)

- Phase A: TiDB 전환 + 온보딩 플로우
- Phase B: 실제 데이터 수집 어댑터(환율·금리·지수·뉴스)
- Phase C: LLM 분석 모듈(스키마 검증·규칙 폴백)
- Phase D: 이메일/카카오 실발송, 관측·운영
- Phase E: UI/UX 고도화(디자인 토큰 기반 전면 개편)
